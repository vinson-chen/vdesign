# 表头单元格交互规范

## 1. 选中列

| 操作 | 条件 | 结果 |
|------|------|------|
| click 表头文本区域 | 非复选框列、未选中此列 | 选中该列，背景高亮为 headerSelected |
| click 表头文本区域 | 非复选框列、已选中此列 | 保持选中（不做任何事） |
| click 表头文本区域 | 非复选框列、已选中其他列 | 切换到该列 |

## 2. 取消选中列

| 操作 | 条件 | 结果 |
|------|------|------|
| click 表格空白区域 | 编辑列面板关闭 | 取消选中 |
| click 表格外部 | 编辑列面板关闭 | 取消选中 |
| click 下拉箭头按钮 | 该列已选中 | 取消选中，同时打开菜单 |
| click 下拉箭头按钮 | 该列未选中 | 不选中列，仅打开菜单 |

## 3. 编辑列

| 操作 | 条件 | 结果 |
|------|------|------|
| 双击表头区域 | 排除下拉箭头按钮 | 若未选中则先选中列；打开编辑面板，标题输入框 autoFocus 并选中文本 |
| click 菜单"编辑列" | — | 若未选中则先选中列；切换到编辑视图 |
| click 保存 | — | 保存标题与列类型，关闭面板 |
| click 取消 | — | 关闭面板 |

**特殊规则：** 编辑面板打开期间，任何面板内操作（点击 Select、输入框、按钮等）都不会取消选中列。

## 4. 调整列顺序

| 操作 | 条件 | 结果 |
|------|------|------|
| 拖拽表头 | 该列已选中、非冻结列、移动 ≥4px | 显示蒙层跟随鼠标，目标列边缘显示蓝色指示线 |
| 释放鼠标 | 目标为有效列 | 移动列到目标位置，保持选中 |
| 释放鼠标 | 目标无效或无位移 | 不改变顺序，保持选中 |

无效目标：冻结列、被拖拽列自身、右邻列 + insert left、左邻列 + insert right（插入后位置不变）。

## 5. 调整列宽

| 操作 | 条件 | 结果 |
|------|------|------|
| 拖拽列右边缘 | 非最后一列 | 实时调整列宽 |

## 6. 列菜单

打开方式：click 下拉箭头按钮。菜单项：

| 菜单项 | 行为 |
|--------|------|
| 编辑列 | 见 §3 |
| 隐藏列 | 从视图隐藏该列 |
| 向左插入列 | 在该列左侧插入新文本列 |
| 向右插入列 | 在该列右侧插入新文本列 |
| 冻结到此列 | 冻结当前列及左侧所有列 |
| 设为分组标题 | 切换该列为分组依据（或取消） |
| 删除列 | 删除该列 |

## 防护规则（实现层面）

| 场景 | 机制 | 位置 |
|------|------|------|
| 表头文本 click 不冒泡到 table | `e.stopPropagation()` | `handleHeaderCellClick` |
| 下拉按钮 click/dblclick 不冒泡 | `e.stopPropagation()` | Button onClick/onDoubleClick |
| 面板内 click/dblclick/mousedown 不冒泡 | wrapper div `stopPropagation` | `HeaderTextCellInner` |
| 面板打开期间不触发取消选中 | `isHeaderPopoverOpenRef` 阻断 | `handleTableClick` / `handleClickOutside` |
| 拖拽释放后 click 不取消选中 | `dragJustEndedRef` 跳过一次 | `handleTableClick` |

# 键盘交互规范（Excel 标准）

## 状态定义

| 状态 | 特征 | 视觉表现 |
|------|------|----------|
| **选中态**（Selected） | 单元格高亮，方向键移动选中位置，按键不输入内容 | 蓝色边框 |
| **编辑态**（Editing） | 单元格内部显示光标，按键输入内容，方向键移动光标 | 蓝色边框 + 内部光标 |

## 状态转换

```
选中态 ──→ 编辑态（F2 / 直接输入 / Backspace）
    ↑            │
    └────────────┘（Enter / Tab / Escape / 点击其他单元格）
```

## 通用键盘规则

| 按键 | 选中态行为 | 编辑态行为 |
|------|------------|------------|
| **ArrowUp** | 向上移动选中单元格 | 移动光标到上一行（多行文本） |
| **ArrowDown** | 向下移动选中单元格 | 移动光标到下一行（多行文本） |
| **ArrowLeft** | 向左移动选中单元格 | 移动光标左移一个字符 |
| **ArrowRight** | 向右移动选中单元格 | 移动光标右移一个字符 |
| **Tab** | 向右移动选中单元格 | **确认编辑 + 向右移动选中** |
| **Shift+Tab** | 向左移动选中单元格 | **确认编辑 + 向左移动选中** |
| **Enter** | 向下移动选中单元格 | **确认编辑 + 向下移动选中** |
| **Shift+Enter** | 向上移动选中单元格 | **确认编辑 + 向上移动选中** |
| **Escape** | 无操作（保持选中态） | **取消编辑，恢复原值，退出编辑态** |
| **F2** | **进入编辑态（光标在末尾）** | 无操作 |
| **直接输入字符** | **进入编辑态（替换原内容）** | 输入字符到光标位置 |
| **Backspace** | **进入编辑态（删除末尾字符）** | 删除光标前一个字符 |
| **Delete** | **删除内容并提交（不进入编辑态）** | 删除光标后一个字符 |
| **Ctrl/Cmd+Z** | 撤回操作 | — |
| **Ctrl/Cmd+Shift+Z** | 恢复操作 | — |

## 单元格类型差异

| 类别 | 类型 | Enter（选中态） | F2（选中态） | 直接输入（选中态） |
|------|------|----------------|-------------|-------------------|
| **可编辑型** | `text`, `editable`, `number` | 向下移动选中 | 进入编辑态 | 进入编辑态（替换原内容） |
| **始终交互型** | `input` | 聚焦内部 Input | 聚焦内部 Input | 聚焦内部 Input |
| **始终交互型** | `select` | 展开下拉菜单 | 展开下拉菜单 | 展开下拉菜单 |
| **始终交互型** | `checkbox` | 切换选中状态 | 切换选中状态 | 切换选中状态 |
| **只读型** | `button`, `icon`, `attachment` | 向下移动选中 | 向下移动选中 | 向下移动选中 |

## 特殊规则

1. **跳过 checkbox 列**：横向导航时自动跳过 checkbox 类型列
2. **中文输入法兼容**：使用 `KeyboardEvent.isComposing` 判断，组合输入期间不触发编辑态
3. **readOnly 模式**：禁用所有进入编辑态的快捷键（F2、直接输入、Backspace、Delete）
4. **分组折叠支持**：导航时自动跳过已折叠分组中的行
5. **数字单元格验证**：直接输入时仅接受数字字符（`0-9`、`-`、`.`）作为初始编辑值
