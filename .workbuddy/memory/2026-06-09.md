# 2026-06-09 工作日志

## 本体论命名格式调整：点分 → 连字符全小写

### 变更内容

- 将 `ontoName()` 函数的输出从 `Button.Primary.Base` 改为 `button-primary-base`（全小写连字符）
- 与项目图标命名规范（`icon-vcell-logo`）对齐，消除点分格式的歧义（像 TS 对象路径）
- 相关 modifier 命名同步调整：
  - leftIcon → `-left-icon`（`button-primary-base-left-icon`）
  - rightIcon → `-right-icon`
  - disabled → `-disabled`

### 命名规则

```
button-{variant}-{size}[-{modifier}]

button-primary-base
button-primary-icon-base
button-cell-icon-sm
button-primary-base-left-icon
button-primary-base-disabled
```

### 确认的规范决策

- 全小写连字符是项目统一命名风格（参考图标：`icon-vcell-logo`）
- `disabled` 是状态后缀，不是 variant（已从 CVA variant 移除，改为正交 boolean + compoundVariants）
